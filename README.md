# ⚡ Hogwarts Sorting Ceremony

An interactive, responsive Hogwarts House Sorting web application designed to evaluate house alignment through nuanced behavioral choices, ethical dilemmas, and everyday scenarios rather than obvious house stereotypes.

🔗 **Live Demo:** [Take the Sorting Quiz](https://lindsayinnesm2005.github.io/hogwarts-sorting-quiz/)

---

## ✨ Features

- **Nuanced Scenarios:** Real-world dilemmas featuring 4 to 6 randomized choices that blend secondary house traits.
- **Dynamic Trait Scoring:** Tracks compound instinctual affinities across Gryffindor, Ravenclaw, Hufflepuff, and Slytherin.
- **Hogwarts Aesthetic:** Styled with custom typography (`Cinzel`, `Cinzel Decorative`, `EB Garamond`), animated progress indicators, and house profile breakdowns.
- **Zero Dependencies:** Pure vanilla HTML5 and JavaScript paired with Tailwind CSS for instant browser rendering.

---

## 🛠️ Built With

- **HTML5 & JavaScript (ES6+)** - State management, array shuffling, and scoring logic.
- **Tailwind CSS** - Modern dark-mode layout, animations, and responsive UI.
- **Google Fonts** - Cinzel Decorative & EB Garamond.
- **GitHub Pages** - Production hosting and automated deployment.

---

## 🚀 Running Locally

1. Clone or download the repository.
2. Open `index.html` in any web browser.
